# Model Selection and Evaluation: Titanic

## Objective
Compare Logistic Regression, Decision Tree, and Random Forest using accuracy, precision, recall, F1-score, and cross-validation.

## How to Run
1. pip install -r requirements.txt
2. python model_selection.py

## Files
- model_selection.py: trains and compares the models
- docs/model_report.md: results and the reasoning for the chosen model
- images/model_comparison.png: comparison chart
- data/: input and output tables
